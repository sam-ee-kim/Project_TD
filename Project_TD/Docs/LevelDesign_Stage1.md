## 테스트 방법

- 맵마다 타워 **4개**를 깝니다 (비용 무시: 1단계 타워 비용이 임시로 모두 50이라 예산으로 맞추면 비용 차이가 구조 차이를 덮습니다).
  - **컨셉**: 의도한 조합 그대로 / **비컨셉**: 컨셉 조합의 칸마다 같은 단계의 컨셉 밖 타워로 바꿔 끼움 (AI) / **전체**: 칸마다 같은 단계의 모든 타워 중 AI
  - **모든 경우의 수**: 타워 11종에서 1~4종을 고른 561가지 조합 (1종 = 같은 타워 4개, 2종 = 보통 2 + 2). 조합의 타워를 1개씩 먼저 놓고 남은 칸은 그 조합 안에서 AI가 채웁니다.
  - 조정 전 수치는 1종·2종 조합과 컨셉·비컨셉·전체만 돌렸습니다 (비교용).
- 웨이브 3개를 실제 게임 코드로 돌립니다. 몬스터 체력 = 기본 × 2.5. 몬스터 수에 배율 ×1 → ×1.5 → ×2 → ×3 → ×4 → ×6 → ×8 → ×12 → ×16 → ×24 → ×32를 곱해(간격 ÷ √배율) 넥서스 피해 20 전까지 버틴 가장 큰 배율이 **점수**입니다.
- **타워 파워량** = ×1 웨이브에서 몬스터가 실제로 잃은 체력 합 · **몬스터 소모량** = ×1 웨이브 처치 수 / 등장 수

## 확인한 점

1. **범위 틱 타워는 크게 내려갔습니다.** 같은 타워 4개 평균: 화염방사 ×12.1 → ×2.6, 분진 ×19.5 → ×6.2, 백린 ×25.2 → ×9. 한 번에 5마리 제한이 몰려오는 물량 웨이브에서 크게 작용했습니다.
2. **플라즈마는 바꾸지 않아서 혼자 압도적입니다.** 같은 타워 4개 평균 ×29로, 다음인 백린(×9)의 3배가 넘습니다. 561가지 조합 중 상위 6개가 모두 플라즈마가 들어간 조합입니다. 회랑 맵이 아니어도 ×25 이상이라, 맵 구조가 고점을 만드는 게 아니라 타워 자체가 강합니다.
3. **단일 대상 타워는 올랐지만 여전히 낮습니다.** 듀얼샷 ×0.1 → ×0.7, 번개 ×0.6 → ×1.2, 냉기 ×1.3 → ×1.8, 전기 ×1.6 → ×2.3. 경로가 긴 E 정예 맵에서만 전기 ×4.7, 냉기 ×3.2로 역할이 보입니다.
4. **미니건은 의도한 방향으로 움직였습니다.** 과열 때문에 평균은 ×4.3 → ×3.6으로 내려갔지만, E 정예 맵에서는 ×5.6으로 단일 대상 타워 중 최고입니다. 물량전 맵(A·C)에서 가장 많이 떨어져 '정예 특화, 다수전 약점'이 수치에 드러납니다.
5. **CC 타워(나노봇·EMP)를 섞으면 오히려 점수가 내려갑니다.** 화염방사 4개 ×2.6 → 화염 + 나노 ×1.7, 화염 + EMP ×2.0, 화염 + EMP + 나노 ×1.5. 미니건 4개 ×3.6 → 미니건 + 냉기 ×3.1. 감속·정지가 화력 1칸을 내준 만큼을 메우지 못합니다. 플라즈마를 빼면 CC 조합 최고는 EMP + 백린 ×7.3입니다.
6. **그래서 의도한 컨셉 조합의 순위가 낮습니다.** A 플라즈마 회랑만 561개 중 1위이고, B·C(화염 + CC)는 450~510위, D 급습은 442위, E 정예는 278위입니다. 화염 + CC로 고점을 보게 하려면 CC 쪽 수치가 더 필요합니다.
7. **EMP는 혼자서는 거의 0입니다.** 1.6초마다 피해 1이라 체력 10(기본 4 × 2.5) 몬스터를 거의 잡지 못합니다. 기계 몬스터 2배 상성은 정예 맵의 우란탱크에서만 의미가 있습니다.
