# 타워 테이블

값은 `Assets/Data/Towers/*.asset` 기준이며 2단계 수치는 임시값이다.
- **지금은 테스트용으로 모든 타워 비용이 50이다.** 원래 비용은 `ProjectSetup.cs`의 Apply*Stats에 남아 있다 (1단계 기본 50 · 화염 70 · 번개 90 · 나노 80 · EMP 100, 2단계 미니건 150 · 전기 140 · 냉기 130 · 혼합분진 160 · 혼합백린 170 · 플라즈마 180, 테크트리 120/270/170/370).
- 주기 = 차지 + 공격 간격.
- DPS = 1회 공격 피해 ÷ 주기 (단일 대상 기준).
- 범위 타워는 대상 한 마리당 DPS다.
