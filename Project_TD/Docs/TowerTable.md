# 타워 테이블

값은 `Assets/Data/Towers/*.asset` 기준이며 2단계 수치는 임시값이다.
- **1단계 타워는 지금 테스트용으로 비용이 모두 50이다.** 2단계는 설계 비용으로 되돌렸다 (진화 비용 = 2단계 비용 − 1단계 비용). 원래 비용은 `ProjectSetup.cs`의 Apply*Stats에 남아 있다 (1단계 기본 50 · 화염 70 · 번개 90 · 나노 80 · EMP 100, 2단계 미니건 150 · 전기 140 · 냉기 130 · 혼합분진 160 · 혼합백린 170 · 플라즈마 180, 테크트리 120/270/170/370).
- 주기 = 차지 + 공격 간격.
- DPS = 1회 공격 피해 ÷ 주기 (단일 대상 기준).
- 범위 타워는 대상 한 마리당 DPS다.

이상효과 판정은 `MonsterManager.ApplyDamage` 한 곳 (값: TowerDef.status, 메뉴 TowerDefence → Setup → Status Effects).
- 얼음·감전 중에는 서리·정전기가 쌓이지 않는다.
- 기계·생물 보너스는 몬스터 속성(`mechanical` / `biological`)으로 붙는다. 지금 몬스터(사버팽·해머헤드·바스티온)는 모두 생물, 기계 몬스터는 나중에 추가.

진화 방법 (게임은 멈추지 않는다):
- 하단 [타워 업그레이드]로 테크트리 창을 연다 → 갈래를 누른다 → 맵에서 진화할 타워를 클릭한다 → [진화].
- 또는 진화할 수 있는 타워를 클릭한다 → 창에서 갈래를 누른다 → [진화].
