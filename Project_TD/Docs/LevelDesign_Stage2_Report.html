확인한 점

  1. EMP 피해 1 → 2는 효과가 컸습니다. 같은 타워 6개 평균 ×0 → ×9이고, 경로가 접히거나 두 줄로 붙는 A·B·C 맵에서는 ×11~×15입니다. 체력 14(일반 4 × 3.5) 몬스터를 1.6초마다 2씩, 파동이 지나가는 모든 몬스터에게 주므로 '못 잡는 타워'에서 '물량을 깎는 타워'로 바뀌었습니다.
  2. EMP + 나노봇이 플라즈마를 뺀 조합 중 1위가 됐습니다. ×0.08 → ×15.5이고, C 2열 진지에서는 ×31.2입니다. 나노필드 안 피해 +20%와 감속이 EMP 파동을 여러 번 맞게 해, 'CC는 조합으로 쓴다'는 의도가 수치로 나왔습니다.
  3. 화염 + CC도 올랐지만 아직 낮습니다. 화염 + EMP ×1.9 → ×3.0, 화염 + 나노 ×1.65 → ×1.84. 의도한 조합은 B ×1.55 → ×2.5(561개 중 410위), C ×1.35 → ×2.05(320위)입니다. 화염방사 자체(같은 타워 6개 ×2.2)가 약해서 CC로 늘려도 바닥이 낮습니다.
  4. 플라즈마는 그대로라 계속 압도적입니다. 같은 타워 6개 평균 ×28.3, 상위 조합은 여전히 플라즈마가 들어간 조합입니다.
  5. D 급습 단거리는 2단계에서도 실패했습니다. 전기·번개·냉기 조합 ×0 (514위). 경로 4~7칸을 빠른 몬스터가 지나가는 동안 단일 대상 타워는 다 잡지 못하고, 비컨셉(같은 단계의 범위·일직선 타워) ×8로 크게 집니다. 이 컨셉의 타워 조합을 다시 정해야 합니다.
  6. E 정예 사냥은 분진이 미니건보다 강합니다. 미니건 조합 ×4 vs 비컨셉 ×21. 분진 6개가 E 맵에서 ×12.9로 가장 강한데, 정예 웨이브의 우란탱크가 기계 속성이라 분진 +30% 상성과 폭발이 겹칩니다. 미니건이 정예를 맡게 하려면 정예 웨이브 구성(생물 정예 비중)이나 미니건 수치를 다시 봐야 합니다.
  7. 나노봇은 혼자서는 여전히 0에 가깝습니다. 같은 타워 6개 ×0.2. 역할이 '다른 타워를 강하게 하는 CC'라 단독 점수는 낮은 게 의도에 맞고, EMP·백린과 섞였을 때(×15.5, ×6.2) 값을 합니다.
